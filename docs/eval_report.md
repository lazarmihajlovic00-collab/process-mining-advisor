## How to read this

- The detectors and the simulator were written by the same builder, so section 1 shows that the detection logic works and where it breaks (mild problems, missing data), not that it generalises to every company. A real log needs its own profile and a check of the thresholds.
- For mechanical levers the estimate removes exactly the manual minutes the simulator removes, so a small error is expected by construction; the interesting rows are the ones where queues and calendars interact (approval escalation) and the combined effect.
- Levers marked `assumed` use an assumed reduction rate (for example 50% fewer price discrepancies). The simulation applies the same assumption, so it only checks the arithmetic, not the assumption.
- Money: hours x 1,100 RSD per hour (assumption), annualised from one quarter.
